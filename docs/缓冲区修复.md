# 候选二：CD 缓冲区修复

用户报错：Cannot raise RLIMIT_MEMLOCK limits；Cannot get mmap for 12587008 Bytes on /dev/zero。

本机配置 CDR_FIFOSIZE=12m，而 RLIMIT_MEMLOCK 软限制为 8 MiB。隔离进程启用未来映射锁定后，申请 12587008 字节返回 EAGAIN，申请 4194304 字节成功；未操作光驱或修改系统配置。

新版生成 wodim 参数时显式提供 fs=，以字节为单位，上限 4 MiB，且不超过进程锁定内存软限制一半。软限制低于 2 MiB 或无法读取时设置 fs=0，直接读取已生成的本地映像文件。保留至少一半预算给进程本身与传输缓冲区；这不是对所有光驱或所有内存限制的硬件保证。

新增两个测试：不同额度下 FIFO 大小计算，以及将测试进程软限制临时降为 64 KiB 后验证实际参数 fs=0，再恢复原限制。既有软件与虚拟多区段测试全部通过。安装包解包后的界面自检通过。

不要求 sudo 运行程序，不修改系统限制、不设置 SUID/capabilities，不自动重试刻录。安装仍使用正常的软件包管理流程。

版本 2.0.0~rc2；尚无本机光驱，实盘与 Windows 读盘验证仍待用户进行。
