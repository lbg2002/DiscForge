## 选择安装包

文件名中的 `ubuntu22.04`、`ubuntu24.04`、`ubuntu26.04` 对应系统版本；`amd64` 适用于常见 Intel / AMD 电脑，`arm64` 适用于 64 位 ARM 设备。请匹配系统与处理器架构，不要混用。

下载 deb 后执行：

```bash
sudo apt install ./discforge_*.deb
```

只把对应系统和架构的一个 deb 放在安装目录中。另附 SHA256SUMS 可核对下载内容。

## 本版内容

- CD 写后直接读取最新区段的 Joliet 目录与文件，核对新旧文件 SHA-256，避免依赖立即挂载。
- 保留原有刻录方式、内存锁定隔离和 FIFO 限制。
- 分别报告写入、校验、弹出结果，显示阶段进度与日志。
- 中文界面、容量单位设置、容量图表；README 含三张页面图。
- 提供 Ubuntu 22.04、24.04、26.04 的 amd64 与 arm64 安装包。
