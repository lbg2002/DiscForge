# 2.0.0-rc5 本地测试

环境：Ubuntu 26.04 amd64，Qt 6.10.2，GCC 15.2。

## 自动验证

- Release 编译，核心测试与离屏界面自检。
- CD/DVD 状态、容量、追加及封盘参数，文件缓存与文件名兼容性。
- wodim 子进程锁页隔离与锁页成功后分配失败的回归复现。
- 分块日志与工具进度，挂载重试，校验和弹出的独立结果。
- 真实 genisoimage 创建两次映像；模拟介质的第二区段位于扇区 20000，第一次卷描述符保持不变。
- 新解析器从第二区段读取 Joliet 目录，并直接核对新旧文件 SHA-256：嵌套中文目录、空文件、超过单次读取批次的文件。
- 从错误区段读取、缺失文件、错误哈希、实际数据损坏、目录记录截断、卷字段大小端不一致、无效卷签名和扇区短读，均不能误报通过。
- deb 结构、解包运行及动态库依赖。

完整输出见 [自动测试输出](自动测试输出.txt)。截图来自程序自检模式，使用演示数据。

## 实盘依据

用户此前候选版日志显示 CD 首次及第二次写入和区段关闭完成。写后立即挂载失败，重新插入后 Ubuntu 能看到新旧文件并正常打开，自动弹出已执行。

这说明此前挂载失败不等于刻录失败；尚无哈希比对结果，也没有 Windows 测试结果。

## 本版限制

当前执行环境无法访问实际光驱节点。本版只读 SG_IO READ(10) 的硬件权限、光驱固件响应、写后立即读取是否就绪仍待实盘确认。自动测试注入扇区读取器，覆盖目录与哈希逻辑，没有假称执行了真实光驱读取。

Windows 兼容性、第三次追加、封盘后读取、原生版 DVD 追加仍待验收。本次按用户要求发布候选版源码，不把尚未验证的项目标为通过。
