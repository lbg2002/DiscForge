# CD 写后直接读取校验

现象：wodim 写入与 Fixating 完成，UDisks2 仍返回“not a mountable filesystem”。重插后 Ubuntu 可读新旧文件，说明不能仅凭写后挂载失败断言刻录失败。

候选五不再以挂载作为 CD 校验的前提：

1. 写入前记录本次区段起点：空盘为 0，追加为写入前 msinfo 的第二个数。
2. 写后只读打开系统光驱，只发送 SG_IO READ(10)，单次最多 32 个 2048 字节扇区。
3. 从区段起点 + 16 查找完整卷描述符及 Joliet 目录。
4. 文件与目录的 extent 是绝对扇区地址；genisoimage 追加映像的卷块数为区段长度，边界采用区段起点加该长度。
5. 核对原有文件与缓存新增文件的 SHA-256，全部通过后才记录 verified。异常不转去读取可能过时的挂载目录，也不重试刻录。

校验程序检查目录边界、大小端字段一致性、文件名、递归深度和目录环，限制目录大小与条目数量。暂不支持 ISO 多 extent 文件、交错文件及非 UCS-2 名称。只有“介质状态变化”或“正在就绪”的读取响应会有限重试，损坏数据不掩盖。

DVD 保留挂载校验。自动弹出独立执行。原写入参数、锁页隔离、FIFO 和独立映像方案不变。

本地测试使用注入扇区读取器与真实 genisoimage 生成的映像；没有访问硬件。本版 SG_IO 硬件路径及 Windows 读取待验收。
